## The problem

Agent systems span model behavior, planning, tools, deployment, evaluation, memory, cost, and security. Learning each concern in isolation makes it hard to see how the system fits together.

## What the repository provides

The repository organizes runnable companion material by chapter for *AI Agents: The Definitive Guide*. It gives readers a direct route from a concept in the book to notebooks and supporting utilities they can inspect and run.

The twelve-part structure covers the progression from foundational agent blueprints through production contracts, secure tool execution, evaluation, operational observation, memory, efficiency, and threat modeling.

## What it demonstrates

- Agent engineering is a system discipline, not a prompt pattern.
- Production readiness depends on contracts, evaluation, operations, and security working together.
- Executable examples make architectural claims easier to test and challenge.
