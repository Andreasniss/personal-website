I design practical sessions around how enterprise agents fail, what evidence they need, and which controls make them operable.

## Verified delivery

I helped run an Amazon Bedrock AgentCore Immersion Day for more than 100 participants. I separately designed and delivered a custom evaluation and policy module extension for a cohort of about 30 participants. Those are two different scopes: the first is the complete learning event, and the second is the material I personally built and taught.

The reviewed workshop page below links the public articles and reference implementations that make the core architecture argument inspectable without publishing private event materials.

## Learn and build with AWS

If you want to build your AWS skills or facilitate a hands-on session with your own team, start with [AWS Builder Center Learn](https://builder.aws.com/learn) for courses, learning plans, labs, and topic guides. The [AWS workshop collection](https://builder.aws.com/build/workshops) provides practical, AWS-authored workshops that you can follow at your own pace.

### AI workshops I recommend

I did not design or publish the AWS workshops below. I have worked through each one myself and recommend them because they cover topics closely related to workshops I have helped run live.

- [Getting Started with Strands Agents](https://catalog.workshops.aws/strands-agents/en-US): build two agent use cases and learn the core Strands Agents development model.
- [Diving Deep into Amazon Bedrock AgentCore](https://catalog.workshops.aws/agentcore-deep-dive/en-US): progress from a working agent toward runtime, identity, memory, observability, and production operations. Complete the introductory AgentCore workshop listed in its prerequisites first.
- [Creating Responsible AI with Amazon Bedrock Guardrails](https://catalog.workshops.aws/bedrockguard/en-US/amazon-bedrock-guardrails): apply safeguards to model inputs and responses and examine how guardrails fit into a responsible AI architecture.
- [Hands-on LLM Evaluation with Amazon Bedrock and Promptfoo](https://catalog.workshops.aws/promptfoo/): compare and evaluate model behavior systematically rather than relying on a few successful prompts.

Use the setup and cleanup instructions on each workshop page, check the prerequisites, and review possible AWS service costs before starting in your own account.
